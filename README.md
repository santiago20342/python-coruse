### Foundational Coding Skills for High School Students

Welcome to the Python Programming Course! This repository is designed to guide you from the very basics of logic to building your own functional applications. Whether you are brand new to coding or looking to sharpen your skills, this course provides a hands-on approach to learning.

## 🎯 Learning Objectives

By the end of this course, you will be able to:

* Understand how computers "think" and process information.
* Write clean, readable code using Python.
* Automate repetitive tasks using loops and logic.
* Build interactive programs that take user input and provide meaningful output.

---

## 🗺️ Course Curriculum

The lessons are organized by complexity. Each folder contains the code examples we discuss in class and a set of practice challenges.

| Module | Topic | Key Concepts |
| --- | --- | --- |
| **01** | **Introduction** | Installation, VS Code, and "Hello World" |
| **02** | **The Basics** | Variables, Data Types (Strings, Integers, Floats) |
| **03** | **Control Flow** | If/Else statements and Boolean logic |
| **04** | **Loops** | For loops, While loops, and iteration |
| **05** | **Data Structures** | Lists, Dictionaries, and Tuples |
| **06** | **Functions** | Reusability, Parameters, and Return values |
| **07** | **Final Project** | Building a text-based game or calculator |

## 💻 Setup Instructions

To get started with the code in this repository, follow these steps:

1. **Install Python:** Download the latest version from [python.org](https://www.python.org/).
2. **Install VS Code:** We use Visual Studio Code as our editor.
3. **Download the Lessons:**
```bash
git clone https://github.com/santiago20342/python-coruse.git

```


4. **Run a script:**
Open a terminal in the folder and type:
```bash
python filename.py

```
